# 💳 FinIntel AI – RAG Based Financial Fraud Decision System
AI-powered fraud detection system using Machine Learning, RAG, ChromaDB, and NVIDIA NIM APIs.

## Project Overview

FinIntel AI is an AI-powered financial fraud detection system that combines:

- Machine Learning
- Retrieval-Augmented Generation (RAG)
- Vector Database Search
- NVIDIA LLM APIs
- AI-Based Financial Reasoning

to detect suspicious financial transactions and generate intelligent fraud investigation reports in real time.

---

## Features

- Fraud Detection using Random Forest Model  
- Real-Time AI Fraud Analysis  
- Retrieval-Augmented Generation (RAG) Pipeline  
- ChromaDB Vector Database Integration  
- NVIDIA LLM API Integration  
- Interactive Streamlit Dashboard  
- Fraud Case Similarity Search  
- AI-Generated Fraud Investigation Reports  
- Financial Risk Intelligence Visualization  

---

## Problem Statement

Traditional fraud detection systems only classify transactions as fraud or normal without explaining the reasoning behind predictions.

This project solves that problem by combining machine learning with AI reasoning and RAG pipelines to provide explainable fraud intelligence and investigation summaries.

## Dataset

The project uses a credit card transaction dataset containing:

- Normal Transactions
- Fraudulent Transactions

Target Variable:
- `0` → Normal Transaction
- `1` → Fraudulent Transaction

The dataset is highly imbalanced, simulating real-world fraud detection challenges.

---

## Project Pipeline

1. Embedding Generation  
2. Vector Database Storage  
3. Similar Fraud Retrieval  
4. NVIDIA LLM AI Analysis  
5. AI Fraud Investigation Report Generation  
6. Streamlit Dashboard Deployment  

---

## 🤖 AI Fraud Intelligence Layer

The AI layer analyzes:

- Fraud patterns
- Suspicious transaction behavior
- Similar historical fraud cases
- Risk levels
- Suggested actions

and generates human-readable fraud investigation reports.
